# Python Quiz Application

A simple command-line based Quiz Application developed using Python. The application displays multiple-choice questions, accepts user answers, checks their correctness, and calculates the final score.

## Features

- Displays multiple-choice questions.
- Provides four options for each question.
- Accepts user input.
- Checks answers automatically.
- Displays correct answers for incorrect attempts.
- Calculates and displays the final score.

## Technologies Used

- Python 3
- Lists
- Dictionaries
- For Loops
- Conditional Statements
- Functions
- User Input Handling
